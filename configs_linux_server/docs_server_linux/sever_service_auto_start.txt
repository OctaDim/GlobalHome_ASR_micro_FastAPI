Способ 2: systemd (Рекомендуемый для серверов)

Лучший способ для управления демонами (автозапуск, логи, перезагрузка).
1. Создаем сервисный файл

Откройте редактор (нужен sudo):
bash

sudo nano /etc/systemd/system/my_python_service.service

Вставьте конфиг (замените пути и команды на свои):
ini

[Unit]
Description=My Python Daemon
After=network.target

[Service]
User=username  # замените на вашего пользователя
WorkingDirectory=/path/to/script
ExecStart=/usr/bin/python3 -m my_module
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target

2. Запускаем сервис
bash

sudo systemctl daemon-reload
sudo systemctl start my_python_service
sudo systemctl enable my_python_service  # автозапуск при загрузке

3. Проверяем статус
bash

sudo systemctl status my_python_service

Логи:
bash

journalctl -u my_python_service -f

4. Остановка / Перезапуск
bash

sudo systemctl stop my_python_service
sudo systemctl restart my_python_service
